# Andrés Herrera — Front-end Developer Portfolio

Personal portfolio showcasing my experience building digital products, responsive interfaces, and user-centered web experiences.

**[View Live Portfolio](https://andresenrique.com/)**

## About the project

This portfolio brings together selected professional work, independent projects, and my approach to front-end development.

I work at the intersection of **front-end engineering, user experience, and product thinking**, with a focus on creating interfaces that are clear, accessible, and thoughtfully implemented.

The website is designed as both a professional presentation and an example of how I approach interface development: from visual hierarchy and component structure to responsive behavior and interaction details.

## Tech stack

- **React** — Component-based interface development
- **Vite** — Development environment and production builds
- **JavaScript** — Application logic and interactions
- **CSS** — Custom styling, responsive layouts, and visual systems
- **Framer Motion** — Interface animations and transitions

## Features

- Responsive layouts across desktop and mobile devices
- Selected projects with descriptions, technologies, and external links
- Professional experience and education sections
- Detailed case study of my work at BeTrust
- Custom visual design and animated interactions
- Direct links to my résumé and professional profiles

## Project structure

The application is organized around reusable React components and section-specific styles, making the interface easier to maintain and evolve.

## Getting started

Clone the repository:

```bash
git clone https://github.com/andreshf44/portfolio-product.git
cd portfolio-product
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Design approach

My work is guided by a few core principles:

**Think in systems.** Understand how components, states, and flows connect within a product.

**Build with intention.** Prioritize clarity, accessibility, and meaningful interactions.

**Connect design and code.** Translate product needs into functional, maintainable interfaces.
